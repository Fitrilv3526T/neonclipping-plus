YouTube

Blocked downloads (common on Colab and VPNs) usually need your login. Export cookies.txt with a browser extension ("Get cookies.txt LOCALLY") while signed in to YouTube.

Remote access

Off. Start the app with NEONCLIPPING_REMOTE=1 to open it from any device with a token link (printed on the server console).
